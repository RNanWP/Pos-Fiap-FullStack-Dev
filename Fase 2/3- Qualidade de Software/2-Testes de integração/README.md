### O que é?

Os testes de integração desempenham um papel fundamental no desenvolvimento de software, permitindo verificar a interação entre os diferentes componentes e módulos do sistema.

Os testes tem como objetivo garantir que as partes individualmente testadas funcionem corretamente em conjunto.

## Tipos de validações

Validação de interface.
Validação de dados.
Validação de fluxo de controle.
Validação de comportamento.
Validação de desempenho

E quem realiza, são os(as):

Equipes de testes.
Especialistas em desenvolvimento.
Equipe de qualidade.
