# 🚀 MeuApp - Aplicação React com Vite

Bem-vindo ao **MeuApp**, uma aplicação desenvolvida em React utilizando Vite, focada em simplicidade, responsividade e interatividade. Este projeto foi criado para demonstrar conceitos fundamentais do desenvolvimento front-end moderno, com componentes reutilizáveis e uma interface amigável.

---

## ✨ Funcionalidades

- **Contador Interativo:** Aumente ou diminua valores com apenas um clique.
- **Lista de Itens Dinâmica:** Adicione e remova itens facilmente, com atualização instantânea.
- **Responsividade:** Layout centralizado e adaptável para diferentes tamanhos de tela.
- **Design Moderno:** Botões estilizados, bordas suaves e espaçamento agradável.

## ⚡ Como executar localmente

1. **Clone o repositório:**

   ```sh
   git clone https://github.com/seu-usuario/meuapp.git
   cd meuapp
   ```

2. **Instale as dependências:**

   ```sh
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**

   ```sh
   npm run dev
   ```

4. **Acesse no navegador:**
   ```
   http://localhost:5173
   ```

---

## 🛠️ Estrutura dos principais arquivos

- `src/App.jsx` - Componente principal da aplicação.
- `src/Contador.jsx` - Componente do contador.
- `src/ListaItens.jsx` - Componente da lista dinâmica.
- `src/App.css` - Estilos globais e responsivos.
